Planned delivery flow

From infrastructure to observable service

  1. Provision

    Terraform automates AWS infrastructure, including EKS with private worker nodes.

  2. Build & publish

    GitHub Actions CI/CD builds the container image and publishes it to Docker Hub.

  3. Deploy

    AWS CodeBuild handles deployment, with Helm deploying NGINX to the EKS cluster.

  4. Route & observe

    An AWS Application Load Balancer routes traffic; CloudWatch, Prometheus, and Grafana are planned for observability.

This is a planned architecture. No deployment, testing, or verification results are claimed.
